# Szent István-bazilika 가상 투어

부다페스트 성 이슈트반 대성당 안을 걸어 볼 수 있는 three.js 가상 투어예요. 위키미디어 공용의 공개 사진을 원근 보정하거나 곡면에 펴서 실제 성당처럼 보이게 만들었어요.

**바로 보기**: https://jeongph.github.io/szent-istvan-tour/

## 할 수 있는 것

- 여덟 장소를 순서대로 둘러보며 한국어 안내를 읽어요(정문, 신랑, 중앙 돔, 주 제단, 성스러운 오른손, 북쪽 수랑, 오르간, 돔 고리).
- 끌어서 둘러보고, 바닥을 누르면 그 자리로 걸어가요. `W A S D`나 방향키로 걷고, 휠로 확대해요. `N`, `P`, `1`~`8`로 장소를 옮겨요.
- 위쪽 시간 막대를 밀면 부다페스트의 실제 해 위치(오늘 날짜 기준)에 맞춰 창으로 드는 빛, 스테인드글라스, 돔 사진의 밝기가 바뀌어요.
- `오르간 소리`를 켜면 잔향이 있는 오르간 화음이 흘러요.
- `사진 출처`에서 쓰인 사진의 저작자와 라이선스를 볼 수 있어요.

## 사진을 어떻게 썼나

사진을 평면에 그대로 붙이지 않았어요.

| 부분 | 방법 |
|---|---|
| 돔, 드럼, 펜던티브 | 바로 아래에서 올려다본 사진 두 장으로 카메라(주점, 초점거리, 축 어긋남)를 역산해 (방위각, 천정각) 지도로 펴고, 셰이더로 곡면에 투영 |
| 후진 반돔(벤추르 모자이크) | 사진 속 명문 띠, 천창, 루네트로 카메라를 풀어 반구 UV로 펼침 |
| 제단화, 스테인드글라스, 반원 열창 | 호모그래피로 원근 보정, 실제 크기로 배치 |
| 대리석, 코퍼 볼트, 소피트, 바닥 | 사진에서 이음매 없는 반복 텍스처로 추출, 실제 타일 크기 적용 |
| 주 제단과 이슈트반 상, 오르간, 성유물함, 성인상 | 사진과 같은 각도로 렌더해 겹쳐 보며 모델링 |

건물 치수(팔 폭 16 m, 주 엔타블러처 17.4 m, 돔 안반지름 11 m)는 돔 사진의 천정각과 오르간 갤러리 실측에서 나왔어요. 자세한 과정은 `research/notes/`에 있어요.

## 실행

```bash
npm install
npm run dev      # http://127.0.0.1:5180
npm run build    # dist/ (GitHub Pages용 base 경로 /szent-istvan-tour/)
npm run preview  # http://127.0.0.1:5180/szent-istvan-tour/
```

WebGL2를 지원하는 최신 브라우저가 필요해요. 느린 기기에서는 자동으로 AO를 끄고 해상도를 낮춰요.

## 폴더

- `src/plan.js`: 평면 치수, 보행 영역, 경로
- `src/arch2.js`, `src/materials2.js`, `src/lighting2.js`: 건축, 실사 재질, 조명
- `src/real/`: 돔 투영 셰이더, 주 제단, 오르간, 성유물함 모듈
- `src/timeofday.js`, `src/atmosphere.js`: 해 위치 계산, 빛줄기와 먼지
- `src/main.js`, `src/controls.js`, `src/stops.js`, `src/minimap.js`: 투어 화면과 조작
- `public/real/`: 사진에서 만든 텍스처와 출처(`credits/*.json`)
- `research/`: 자료 조사 지침과 작업 노트, 사진 대조 이미지
- `harness.html`, `arch-test.html`: 개발용 미리보기 페이지(배포에는 포함되지 않음)

## 라이선스와 출처

- 사진 기반 텍스처(`public/real/`)는 CC BY-SA 사진에서 나온 2차 저작물이라 **CC BY-SA 4.0**으로 배포해요. 자세한 내용은 `public/real/LICENSE.md`를 보세요.
- 원본 사진의 저작자와 라이선스는 `public/real/credits/*.json`과 화면의 `사진 출처` 창에 있어요.
- 건물과 미술품 자체는 저작권 보호 기간이 끝난 퍼블릭 도메인이에요.

## 한계

- 높이는 돔 사진 각도에서 나온 값이라 ±3% 정도 오차가 있어요.
- 모서리 칸 내부는 참고 사진이 없어 추정으로 만들었어요.
- 조각상, 천사, 오르간 장식은 가까이서 보면 단순해요.
- 동서 아치 밑면은 원본 사진이 없는 영역이라 대비가 낮아요.
